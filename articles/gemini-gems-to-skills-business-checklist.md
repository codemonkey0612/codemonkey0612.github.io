業務でGeminiのGemを使っている会社は多いと思います。Gemとは、指示文や参考資料を保存して作る「用途別のGemini」のことです。そのGemが、2026年11月から「スキル」という仕組みへ順に移ります。個人用アカウントの場合、残り時間は1週間ほどです。

結論から書きます。慌ててGemを作り直す必要はありません。Gemは自動でスキルへ移されるからです。ただし、参考資料の一部は引き継がれない可能性があります。今週中に社内のGemの棚卸しと、指示文・参考資料の控えを済ませてください。そのうえで、個人アカウントで動く「業務Gem」の扱いを決めます。

## 何が起きたのか：Google公式ヘルプが案内する移行スケジュール

Googleの公式ヘルプ [About the transition from Gems to skills](https://support.google.com/gemini/answer/18560919?hl=en) が移行の予定を案内しています。個人用Googleアカウントの移行は2026年11月からです。仕事用・学校用アカウントは2027年からです。

18歳以上の個人用アカウントの日程は次のとおりです。

- 2026年11月17日：Gemがスキルへ移行する。元のGemは読み取り専用（閲覧のみで編集できない状態）になる
- 2026年12月17日：GeminiアプリからGemが削除される
- 18歳未満の個人用アカウント：後日移行する

同じヘルプの説明だと、Gemは対応ファイルも含めて自動でスキルへ作り直されます。一方で、スキルが対応していない形式のファイルは移行されないとも明記しています。

[Googleの公式ブログ](https://blog.google/products-and-platforms/products/gemini/automate-tasks-with-skills/)では、組織向けの時期も示されています。Workspaceのビジネス・エンタープライズ・非営利向けは2027年3月です。教育機関向けは2027年6月です。Workspaceとは、Gmailやドライブなどを会社単位で契約・管理するGoogleのサービスです。なお、Google Labsが作った「Gems by Google Labs」はスキルへ移行されず終了します。

## 影響を受けるのは誰か：個人用と仕事用アカウントの違い

同じ会社の中でも、アカウントの種類によって期限が大きく違います。[Workspace管理者向けヘルプ](https://knowledge.workspace.google.com/admin/generative-ai/gemini-app/about-the-transition-to-skills)の日付も合わせて整理します。

| アカウントの種類 | Gemが使えなくなる時期 | 注意点 |
| --- | --- | --- |
| 個人用（18歳以上） | 2026年11月17日に読み取り専用 | 12月17日に削除 |
| Workspace（ビジネス・エンタープライズ） | 2027年3月1日 | 管理者から利用者へ周知 |
| Workspace（教育機関） | 2027年6月1日 | 同上 |
| 個人用（18歳未満） | 後日 | 日程は未定 |

管理者向けヘルプによると、WorkspaceのGeminiアプリ内のGemは「下書きのスキル」へ自動で移されます。ただし、現時点でスキルはGeminiアプリとWorkspaceアプリの間で同期しません。Workspaceアプリ上のGemは、Google Workspace Studioを使い手作業で作り直す必要があると案内されています。Workspace Studioは、Workspaceのアプリ側でスキルを作る場所として案内されているツールです。

いちばん急ぐ必要があるのは、社員が個人のGmailアカウントで業務用のGemを作っているケースです。会社のWorkspaceには2027年まで猶予があります。一方、個人アカウントのGemは来週から編集できなくなります。

## Gemとスキルはここが違う：呼び出し方・組み合わせ・SKILL.md形式

### 呼び出し方

Gemは専用の画面に切り替えて使う仕組みでした。スキルは、進行中のチャットで「/」とスキル名を入力して呼び出します。有効にしたスキルの中から、依頼内容に合うものをGeminiが自動で使うこともあります（[Gemini Appsヘルプ](https://support.google.com/gemini/answer/17094296?hl=en)、[gihyo.jp](https://gihyo.jp/article/2026/09/gemini-skills)）。[Impress Watch](https://www.watch.impress.co.jp/docs/news/2144104.html)は、呼び出しの記号が「@」へ変わる予定だと報じています。社内マニュアルに記号を書く場合は、事前に画面の表示も確認してください。

### 組み合わせ

1つのチャットで複数のスキルを同時に使えます。たとえば「議事録の型」と「社内の表記ルール」を別々のスキルにして、必要なときだけ組み合わせる使い方ができます。用途ごとにGemを丸ごと作る必要が減ります。

### SKILL.md形式

スキルはファイルからも作成できます。SKILL.mdというファイルか、それを最上位のフォルダに含むzipファイルを読み込めます（[Gemini Appsヘルプ](https://support.google.com/gemini/answer/17094296?hl=en)）。SKILL.mdは、見出しや箇条書きを記号で書くMarkdown形式のテキストファイルです。テキストなので、社内で保管したり変更履歴を残したりしやすい点が利点です。

### 現時点でできないこと

移行ヘルプでは、Workspaceのアプリをつなぐ「Connected Apps」との併用は可能とされています。一方で、CanvasやDeep Researchとはまだ併用できません。Canvasは、文書やコードを横に並べて編集する画面です。Deep Researchは、多数のWebページを調べてレポートにまとめる機能です。

ファイルにも制限があります。[gHacksの報道](https://www.ghacks.net/2026/11/05/google-will-turn-gemini-gems-into-skills-on-november-17-and-remove-the-old-gems-on-december-17/)では、スキルのファイル容量の上限が100MBとされています。上限を超えると大きいファイルから削除されるそうです。旧Office形式（.doc、.xls、.ppt）や圧縮ファイル、音声・動画も移行されないと報じられています。共有機能やドライブのファイル追加について、公式ブログは発表時点で「数週間以内」の対応を予告していました。最新の状況は画面で確認してください。

## 今週やること：Gemの棚卸しと指示文・参考資料の保存

個人用アカウントの期限は11月17日です。次の5つの手順は、今週中に終えておくことをおすすめします。

1. Gemの一覧を集める。部署単位で、利用者とアカウントの種類、Gemの名前を書き出してもらう。
2. 指示文を控える。Gemの名前・説明・指示をそのままテキストにコピーして保存する。
3. 参考資料の原本を確認する。Gemへ入れたファイルについて、原本の保存場所を記録する。
4. 引き継がれにくいファイルを洗い出す。旧Office形式は新しい形式（.docxなど）に変換しておく。
5. 重要度を付ける。止まると業務が困るGemは「高」とし、移行後すぐ動作を確かめる。

控えは、次のような形式のファイル1つにまとめると扱いやすくなります。項目名や値は架空の例です。

```yaml:gem-inventory.yaml
# Gem棚卸しの記録（1つのGemにつき1ブロック）
- name: 見積メール下書き            # Gemの名前
  owner: 営業部 担当者A              # 作成者・管理者
  account: 個人用                    # 個人用 / Workspace
  importance: 高                     # 高 / 中 / 低
  instructions_file: gems/estimate-mail.md   # 指示文を保存した場所
  reference_files:                   # 参考資料と原本の保存場所
    - file: 料金表.xls
      original: 共有ドライブ/営業/料金表
      note: 旧形式のため.xlsxへ変換する
  uses_canvas_or_deep_research: false  # 未対応機能に頼っているか
  contains_confidential: true          # 顧客情報や社外秘を含むか
```

`account`と`contains_confidential`の2項目は、次の章の判断に直接使います。`instructions_file`には、手順2でコピーした指示文の保存先を書きます。保存先には、個人のパソコンでなく会社の共有ドライブなどを選んでください。

確認用のチェックリストもまとめます。

- 個人用アカウントで作られた業務Gemを把握できている
- すべての重要なGemについて、指示文をテキストで控えた
- 参考資料の原本の保存場所がわかっている
- 旧Office形式や圧縮ファイルを変換した
- CanvasやDeep Researchに頼るGemを把握できている
- 11月17日以降、重要なGemの動作確認をする担当者を決めた

## やらなくてよいこと：慌てた作り直しや、すぐの乗り換え

期限が近いと、全部を作り直したくなるかもしれません。しかし、次のことは急がなくて大丈夫です。

- 11月17日より前に、全Gemを手作業でスキル化すること。自動で移行されるため、控えを取っておけば十分である。
- 別のAIツールへすぐに乗り換えること。指示文と参考資料さえ手元にあれば、移る先は後で選べる。
- WorkspaceアカウントのGemを今すぐ移すこと。期限が2027年なので、まず個人用アカウントを優先する。
- 使っていないGemまで整えること。一覧への記載だけ済ませ、不要なものは移行後に削除する。

大切なのは、Gemの中身を「Googleの画面の中にしかない状態」から抜け出させることです。控えがあれば、どの道を選んでもやり直せます。

## 個人アカウントの「業務Gem」をどうするか：社内AIへ移す判断基準

棚卸しをすると、個人アカウントで動く業務Gemが見つかることがあります。作った人が退職すると、会社はその中身を確認できなくなります。今回の移行は、こうしたGemを見直すよい機会です。

次のどれかに当てはまるGemは、会社が管理できる場所へ移すことを検討してください。

- 顧客情報や社外秘の資料を参考資料に入れている
- 複数の社員が同じGemを使っている
- そのGemが止まると日々の業務も止まる
- 作った人がいなくなると、誰も直せない
- 回答の根拠を、元の資料で確かめる必要がある

移す先は大きく2つあります。1つは、会社のWorkspaceアカウントでスキルとして作り直す方法です。手軽ですが、組織の契約や設定で使える機能が変わるため、管理者と事前に確認してください。もう1つは、社内専用のAIの仕組みを用意する方法です。

後者の代表がRAGです。RAGとは、社内文書を検索してから、その内容をもとにAIが回答する仕組みです。私は中堅企業向けのRAG文書解析システムの開発で、回答への参照元表示を実装しました。情報が足りないときは回答を控えるようにもしました。中堅IT企業向けのAI業務基盤では、企業単位のデータ分離やロール（役職や担当）別の権限、ログ管理を実装しました。

この経験から、判断の軸は「閲覧してよい人の範囲」と「後から根拠を確かめられること」の2つだと考えています。権限やログが必要なら、個人向けアプリのスキルより社内の仕組みのほうが向いています。逆に、文体の調整や定型文の作成だけなら、会社アカウントのスキルで十分なことが多いです。

判断に迷ったら、まず「顧客情報が入っているか」だけを確認してください。入っているGemは、個人アカウントから外すことを最優先にします。

## まとめ

- 18歳以上の個人用アカウントでは、2026年11月17日にGemがスキルへ移行する。削除は12月17日である。
- Workspaceはビジネス・エンタープライズ向けが2027年3月1日である。教育機関向けは2027年6月1日である。
- Gemは自動で移行される。ただし、一部のファイルが引き継がれない可能性がある。
- 今週は、Gemの棚卸しと指示文・参考資料の保存を優先する。
- 個人アカウントの業務Gemの移し先は、情報の機密性と確認のしやすさで決める。
