ニュースや取引先から「Javaの脆弱性に注意」と聞くと、ドキッとしませんか。
自社でJavaを使っている自覚がなくても、気になってしまう方は多いと思います。

この記事では、そうなったときの動き方をまとめます。
専門的な作業は不要です。システムに詳しい発注先や保守担当へ、4つの質問を投げれば足ります。

## 今回の注意喚起の内容

[IPAの「Oracle Java の脆弱性対策について(2026年11月)」](https://www.ipa.go.jp/security/security-alert/2026/1118-jre.html)によると、Oracle Javaのセキュリティ更新プログラムは2026年11月18日(日本時間)に公表されました。
IPAは、最新版への更新を求めています。

用語を先に確認します。

- Java：業務システムなどの内部で広く使われる、プログラミング言語と実行環境である。
- 脆弱性：攻撃に悪用されかねないプログラムの欠陥である。
- セキュリティ更新プログラム：その欠陥をふさぐ修正版である。

IPAは、悪用された場合の被害として次の2つを挙げています。

- アプリケーションが異常終了する
- 攻撃者にパソコンを制御される

対策は、Oracle社が提供する最新版への更新です。

## 対象となるバージョン

IPAのページが対象としているのは、次のOracle Java SEです。

- 27.0.1.0.3
- 25.0.5.0.3
- 21.0.13.0.3
- 17.0.21.0.3
- 11.0.33.0.3
- 8 Update 511b33

長い番号を覚える必要はありません。
確認したいのは、先頭の「8、11、17、21、25、27」という大きな世代です。

## 「うちは関係ない」と決めつけられない理由

Javaは、利用者の目に見える形で表示されることが少ない技術です。
たとえば、次のような場所で動いていることがあります。

- 受発注や在庫管理を担うサーバー
- 帳票の出力や社内ワークフローの仕組み
- 開発や運用で使う管理ツール

また、Javaを使っていても、Oracle以外が配布するものという場合もあります。
外から見て判断するのは難しいので、中身を知る人に尋ねるのが確実です。

## 発注先に送る4つの質問

そのままメールやチャットに貼れる形にしています。
答えがあいまいなら、把握が足りていない可能性があります。

### 質問1：うちのシステムでJavaは使われていますか

使っているシステムを一覧にしてもらいます。
サーバーに加えて、社内パソコンの業務ソフトも対象に含めてください。

### 質問2：使っているのはOracle Javaですか

IPAが対象とするのはOracle Java SEです。
配布元が違えば、対応のやり方も変わります。最初にここを仕分けます。

### 質問3：バージョンは対象に当たりますか

先ほどの世代と突き合わせてもらいます。
回答は「対象」「対象外」「更新済み」のどれかにしてもらうと、判断が楽になります。

### 質問4：いつ、どんな手順で更新しますか

確認したいのは次の4点です。

- 更新の予定日
- 事前の動作確認の有無
- 更新中に業務が止まる時間
- 費用がかかるかどうか

私なら、返信の期日をあらかじめ決めて送ります。
期日がないと、確認が後回しになりやすいからです。

## 不安なときにやりがちなこと

次の行動は避けてください。

- 自分でJavaをダウンロードして入れ替える
- 出所の不明なサイトから更新ファイルを取得する
- 「怖いから全部止める」と決める
- ニュースの見出しだけで判断する

業務システムは、特定のバージョンを前提に作られている場合があります。
勝手に入れ替えると、動かなくなるかもしれません。

影響範囲を知らずに止めてしまうと、業務への打撃のほうが大きくなる恐れもあります。
まず、対象かどうかを確かめましょう。

## 更新後に確認したいこと

更新して終わりにはしません。
私なら、発注先に次の4点をお願いします。

- 更新後のバージョンを文書で受け取る
- 受注入力や帳票出力など、主要な業務を担当者が試す
- 異常終了や動作の遅さがないか、数日間観察する
- 更新作業の記録を保守履歴に残す

不具合が出たら、症状と発生時刻を保守担当に伝えます。
元に戻す手順があるかも、事前に聞いておくと安心です。

なお、IPAのページにはOracle社のライセンス変更についての記載もあります。
自社の使い方が条件に合うかは、専門家に確認してください。

## まとめ

不安になったら、自分で調べ込む前に、聞く相手を決めることが大切だと私は考えます。
使っているか、どの配布元か、どのバージョンか、いつ更新するか。この4点が分かれば、判断の材料はそろいます。

一次情報はIPAのページです。
見出しの勢いに流されず、そこを基準に落ち着いて進めてください。
